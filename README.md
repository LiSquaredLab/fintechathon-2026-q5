# 2026 FinTechathon 赛题五 · 基于原始量价数据的股票收益预测

量化选股流水线：从原始量价数据出发，构建多维复合因子，用 LightGBM 截面排序模型预测未来一日收益率，并针对官方复合评分公式（Rank IC 40% + Top 组年化超额 30% + 预测换手率 30%）做了专门优化。

## 结果

结果按两种口径报告：

- **竞赛口径**（`submission.csv`，正式提交）：完全按官方 `evaluate.py` 计算，只剔除涨停股。
- **可交易口径**（`submission_tradable.csv`）：在竞赛口径基础上，把无行情行（未上市、已退市或停牌，见[实现细节](#需要注意的实现细节)）的 `pred` 置为 -999，使其不进入 Top10%。这是交易约束，用于说明策略在真实交易中的表现，不是更准确的收益预测。

验证段（2019-03-06 ~ 2024-12-31，1416 个交易日，样本外）：

| 指标 | 基线（未平滑） | 竞赛口径 | 可交易口径 |
|---|---|---|---|
| Rank IC | 0.0620 | 0.0543 | 0.0544 |
| Top10% 组年化超额 | 0.2711 | 0.2185 | 0.2192 |
| 预测换手率 | 0.8734 | 0.1177 | 0.2984 |
| **官方综合得分** | 0.1441 | **0.3520** | 0.2980 |

竞赛口径按时间分段：

| 区段 | 交易日 | Rank IC | 年化超额 | 换手率 | 综合得分 |
|---|---|---|---|---|---|
| 最近 250 日 | 250 | 0.0556 | 0.1906 | 0.2440 | 0.3062 |
| 最近 500 日 | 500 | 0.0605 | 0.2147 | 0.2073 | 0.3264 |
| 全验证段 | 1416 | 0.0543 | 0.2185 | 0.1177 | 0.3520 |

测试期（2025-01-02 ~ 2026-06-08，344 个交易日）预测换手率：竞赛口径 **0.2395**，可交易口径 0.2869。

说明：

- 两种口径的 IC 和超额收益几乎相同，因为官方这两项只用有标签的行计算，而无行情行几乎都没有标签。差别几乎全部在换手率上。
- 验证段的换手率不能直接和测试期比较：验证段中无行情行占 12.16%（早年未上市的股票多），测试期只占 2.80%。越靠近测试期的区段越有参考价值。
- 选参窗口（验证段最后 250 日）参与了参数选择，它的指标不是独立留出成绩。测试集没有标签，无法给出测试期的 IC 和收益。

完整数字见 `run_summary.json`，报告写作建议见 [`REPORT_NOTES.md`](REPORT_NOTES.md)。

## 快速开始

```bash
pip install pandas numpy scipy scikit-learn lightgbm matplotlib seaborn
```

将官方数据放到 `赛题五数据/` 目录下（`训练集.csv`、`测试集_X.csv`），然后：

```bash
python fintechathon_q5.py
```

输出：`submission.csv`、三张 300 DPI 图表、`model_final.txt` 和 `run_summary.json`。全量运行约 5 分钟（8 核）。

常用参数：

```bash
python fintechathon_q5.py --demote_halted                               # 额外导出可交易版 submission_tradable.csv
python fintechathon_q5.py --tune 0 --anchor_weight 0 --smooth_span 20   # 跳过网格搜索，用固定参数
python fintechathon_q5.py --skip_submission                             # 只做本地验证
python fintechathon_q5.py --n_jobs 4                                    # LightGBM 线程数（默认使用全部 CPU 核心）
python fintechathon_q5.py --max_train_rows 3000000                      # 小样本试跑：取最近的交易日，凑满约 300 万行
```

`--max_train_rows` 从最近的交易日往前取完整的交易日。每一折要在训练期末尾留 60 个交易日做早停，样本太少时模型会退化（例如 40 万行只有 87 个交易日，各折 `best_iter` 都是 1），只能用来检查流程能否跑通。300 万行约对应最近 646 个交易日，各折能正常训练，用时约 2 分钟。

## 方法

### 数据清洗与行情时间轴

先在完整行情上构建因子并做逐日截面标准化，保留缺失与涨跌停日期的时间位置；下列过滤条件仅决定哪些样本参与拟合，外层验证和预测仍保留全市场，以对齐官方换手率和收益指标口径。

- 拟合时剔除 `y_ret_1d` 缺失样本（全样本约 14.5%，训练集尾部约 30%，主要来自停牌、未上市等情况）；
- **剔除涨停股**（`flag_limit_up == 1`）：涨停股次日往往无法以收盘价买入，保留会造出无法实现的虚高收益，这是官方评分口径明确要求的；
- 训练时同时剔除跌停股（次日收益同样失真）。

### 因子工程（36 个因子）

| 类别 | 因子 |
|---|---|
| 动量 / 反转 | 1/5/10/20 日滚动收益、5 日反转、MA5/MA20 偏离度 |
| 日内形态 | 振幅、高低区间占比、收盘位置、跳空 |
| 波动率 | 5/20 日收益标准差、短长波动率比、20 日收益偏度 |
| 量价协同 | 成交量 5/20 日变化率、成交额强度、均价偏离度、5/10 日量价相关 |
| 流动性 / 规模 | 换手代理、对数成交额、成交量波动率 |
| Beta 代理 | 个股收益对截面中位收益的 20 日滚动敏感度 |
| 补充形态与位置 | 2/60 日收益、日内收益、上下影线、实体比例、20/60 日价格位置 |
| 截面排名 | 1 日收益和 20 日收益的逐日截面百分位 |

全部因子按 `trade_date` 做**逐日截面 Z-Score 标准化**，剥离大盘 Beta 与市场整体波动，使模型只看到"个股相对当日市场"的强弱。

### 交叉验证

严格按 `trade_date` 切分的 **Purged Time-Series CV**（5 折）。每折验证段之前留 6 个交易日 embargo 隔离带 —— 因为 t 日标签 `y_ret_1d` 的收益实现窗口跨越到 t+1，不留间隔就会与验证段起始日重叠，构成未来数据泄露。

### 压低换手率（本方案的关键）

官方换手率项 `(1 - turnover) × 0.3` 按测试期 344 个交易日取平均，对排名影响很大。方案用**个股时序 EMA 平滑**：对每只股票的预测序列做因果指数平滑，抹平 Top10% 边界附近的排名抖动（成分股大进大出正是抖动造成的）。纯"过去→现在"滤波，不引入未来信息。未平滑的模型预测换手率是 0.873，平滑后竞赛口径换手率降到 0.118、可交易口径降到 0.298，Rank IC 为 0.054。

参数（平滑跨度 span、动量锚权重 w）通过验证段末尾 250 个交易日的网格搜索选定，选参使用竞赛口径。**只用近端窗口而非全验证段**，因为验证段早期与测试期相隔数年、市场结构不同，全段平均会系统性偏向"高 IC 高换手"的组合。默认受限网格最优为 `w=0, span=20`。扩展网格按末尾 250 日复合分会选 60；我们根据全验证段 IC、超额收益及可解释性的取舍，主动保留 20。这是人工选择，不是扩展网格的最优解。

### 模型

`lgb.LGBMRegressor`，`objective='huber'`（对收益率厚尾稳健），`learning_rate=0.03`、`num_leaves=63`、`max_depth=6`、`min_child_samples=300`、`lambda_l2=5.0` 等平滑正则约束，配合早停。每折在训练期内部末尾留出 60 个交易日用于早停，并留 embargo；外层验证不参与树数选择。外层模型在该折完整训练期重新拟合，用于样本外预测。最终模型以各折早停树数的中位数（当前为 153）在全部可训练样本上重新拟合，再输出截面百分位排序。

## 需要注意的实现细节

**`vol` 字段单位是股，不是手。** 以 000001.SZ 在 2025-01-02 的数据为例，`amount / vol = 11.56`，与真实股价一致。因此均价偏离度因子应为 `(amount / vol) / close` 相对其自身 20 日均值的偏离；若按 `amount / (vol * 100) / close` 计算，得到的将是一个近似恒等于 0 的常数，因子完全失效。

**数据是满面板，包含大量无行情的占位行。** 每个交易日都有全部 4,650 个 `ts_code`，未上市、已退市的股票也有一行，其 `vol`、`amount` 为缺失值（不是 0）。验证段的无行情行中，95.4% 是上市前、3.1% 是退市后、只有 1.5% 是区间内停牌；测试期分别为 74.6%、17.6%、7.8%。这些行的特征缺失后被按截面中位数填充，模型给出的预测恰好很高：当前 36 因子模型的无行情行截面百分位中位数约 0.977，约 89.5% 落在前 10%，在竞赛口径下 Top10% 中日均占 25.54%，从而压低换手率。这符合官方规则，所以竞赛提交保留它们；可交易口径则把它们排除。

**测试期需要拼接历史才能算长周期因子。** 测试集首日若缺前 20 个交易日历史，MA20、20 日波动率等因子会整列为 NaN。脚本把训练集末尾 90 个交易日与测试集拼接后统一计算因子，再切回测试期 —— 只用到测试日之前的历史，不产生泄露。拼接使用清洗前的连续行情，避免标签缺失和涨跌停样本被删除后破坏滚动窗口。

收益率因子严格沿每只股票自己的时间轴计算，并显式保留缺失价格产生的缺口，避免股票边界串入其他股票的价格或由前值填充制造人工收益。动量锚按交易日做截面百分位排名，确保训练和测试只使用当日横截面信息。

## 特征重要性观察

量能变化类因子（`f13_vol_chg_5d`、`f14_vol_chg_20d`）的分裂增益仍居前，其次是均价偏离度 `f16_price_dev`、收盘位置和 K 线形态。26→36 因子的全验证竞赛复合分提高约 0.0086，主要来自换手率；可交易口径仅提高约 0.0012，不能据此证明收益预测能力提升。这符合 A 股日频"量先于价"的经验。注意：模型原始预测的换手率很高（0.873），低换手来自 EMA 平滑，不能用量能因子来解释。

## EMA 对照实验复现

```bash
python fintechathon_q5.py --ema_grid 0 3 5 8 12 20 30 40 50 60 --out_dir ema_experiment --skip_submission
```

该命令会按扩展网格复合分选出参数；采用 EMA20 的提交可用 `--tune 0 --anchor_weight 0 --smooth_span 20` 复现。固定参数模式现在也会在选参窗口记录对应得分。36 因子是基于已观察验证段筛选的候选，没有独立留出段；旧 26 因子版本可在提交历史中追溯。
